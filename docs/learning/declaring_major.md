# 专业确认
<!-- 2026 TODO -->
> 受到招生政策调整影响，专业分流规则可能发生较大变动。请同学们密切关注[本科生院官网-学籍管理-主修专业确认及转专业](https://bksy.zju.edu.cn/28340/list1.htm)发布的相关通知，本页内容**仅供参考**。

据学校招生推文，2026级的专业确认将采取小类任选的形式。
![](../assets/major.webp)

- 求是学院各学园专业确认时间为大一冬学期（12月份）。
    > 本章节介绍的主修专业确认政策主要面向求是学院的同学，竺可桢学院的主修专业确认政策详见本指引的[“学习-竺院专题”](./intoCKC.md)部分。
- 竺可桢学院部分需要确认专业的平台，确认时间为大一春夏学期。
- 少数已确认专业（三位一体、提前批等）或小类内仅含一个专业的学生，无需参加主修专业确认。
- 在专业确认后直至大三前，除约定专业外，还有申请跨院系转专业的机会，大三及以后有院内转专业的机会。
